# Inventario y Distribución de Ayudas

Sistema de **inventario y registro de ayudas** para la Casa de Morena.  
Permite gestionar productos (como medicinas, sillas de ruedas, etc.) y registrar a quién se entregan, con foto y datos del beneficiario.

---

## ✨ Características
- Gestión de productos (alta, baja, edición).
- Registro de beneficiarios con CURP, nombre, domicilio y teléfono.
- Registro de entregas con foto del beneficiario y del producto entregado.
- Estadísticas y reportes de entregas.
- Interfaz con estilos del [Gobierno de México](https://framework-gb.cdn.gob.mx/).

---

## 🚀 Tecnologías usadas
- **PHP 8+**
- **MySQL / MariaDB**
- **HTML5, CSS3, JS**
- **Bootstrap / Framework GB**
