Inventario Morena (PHP + MySQL) - Corrección completa + GOB.mx
-------------------------------------------------------------------
1) Importa sql/inventario_morena.sql en MySQL.
2) Ajusta credenciales en config.php si hace falta.
3) Abre http://localhost/inventario_morena/login.php
   - Si no existe ningún usuario, te llevará a setup_admin.php (crear admin).
4) Roles:
   - admin: gestionar productos, usuarios y entregar.
   - operador: registrar entregas y ver historial.
5) La carpeta /uploads debe tener permisos de escritura.
6) UI basada en Framework GOB.mx (CSS/JS CDN).
